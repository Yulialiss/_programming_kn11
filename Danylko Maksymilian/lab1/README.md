Мета роботи

Метою лабораторної роботи є ознайомлення з базовою структурою програми мовою C++, вивчення основ введення та виведення даних, а також набуття початкових навичок роботи з системою контролю версій Git та платформою GitHub.

Теоретичні відомості

Мова програмування C++ використовується для створення консольних і графічних програм.
Для введення та виведення інформації в C++ застосовується бібліотека <iostream>, яка містить об’єкти cin та cout.

Оператор cout використовується для виведення текстової інформації та значень змінних у консольне вікно.

Хід роботи

Під час виконання лабораторної роботи було створено консольну програму мовою C++.
Програма виводить інформацію про лабораторну роботу, номер варіанту та ім’я студента за допомогою оператора cout.

Також було створено Git-репозиторій та виконано завантаження файлів програми на платформу GitHub.

Файли з програмою розміщено у власному Git-репозиторії:
https://github.com/Yulialiss/_programming_kn11.git

Висновок

У результаті виконання лабораторної роботи №1 було отримано початкові навички програмування мовою C++.
Опановано базову структуру програми, використання бібліотеки <iostream> та виведення інформації в консоль.
Також набуто практичного досвіду роботи з системою контролю версій Git і сервісом GitHub, що є важливою складовою сучасної розробки програмного забезпечення.

Мета роботи

Ознайомитися з основними типами даних мови програмування C++ та навчитися використовувати умовні оператори if, else для розв’язання практичних задач.

Теоретичні відомості

Мова програмування C++ підтримує різні типи даних, які використовуються для зберігання та обробки інформації.
Основними з них є:

int — для зберігання цілих чисел;

float — для дійсних чисел з одинарною точністю;

double — для дійсних чисел з подвійною точністю;

bool — логічний тип даних, що приймає значення true або false.

Для реалізації розгалужених алгоритмів у C++ використовується умовний оператор if.
Оператор else дозволяє задати альтернативні дії у випадку, якщо умова не виконується.

Завдання 1

Знайти мінімальні значення серед двох пар чисел.

Завдання 2

Обчислити значення функції за умовою.

Хід роботи

Під час виконання лабораторної роботи було створено програму мовою C++ з використанням базових типів даних та умовних операторів.
У першому завданні застосовано оператори порівняння та умовний оператор if для знаходження мінімальних значень серед заданих пар чисел.
У другому завданні реалізовано розгалужений алгоритм для обчислення значення функції залежно від значення змінної x.

Мета роботи

Ознайомитися з операторами циклів мови програмування C++, навчитися використовувати цикли for та while для розв’язання практичних задач.

Хід роботи

Під час виконання лабораторної роботи було створено програми мовою C++ з використанням циклічних операторів.
У першому завданні виконано табулювання математичної функції на заданому проміжку з використанням циклу for, а також знайдено максимальне та мінімальне значення функції.
У другому завданні за допомогою циклу було обчислено значення числового добутку за заданою формулою.

Використання циклів дозволило автоматизувати повторювані обчислення та ефективно накопичувати результати.
Результати роботи програм виведено на екран за допомогою оператора cout.

Файли з програмами розміщено у власному Git-репозиторії:
https://github.com/Yulialiss/_programming_kn11.git

Висновок

У результаті виконання лабораторної роботи №3 було поглиблено знання з використання циклів у мові програмування C++.
Отримано практичні навички застосування циклічних операторів для табулювання функцій та обчислення математичних виразів.
Робота сприяла закріпленню теоретичних знань і формуванню практичних навичок програмування, необхідних для подальшого вивчення об’єктно-орієнтованого програмування.

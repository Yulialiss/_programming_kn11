Мета роботи
Ознайомитися з базовими типами даних мови C++, операціями введення та виведення інформації, а також з використанням умовних операторів if / else.

Теоретичні відомості
У мові C++ умовні оператори дозволяють виконувати різні дії залежно від виконання логічної умови. Найпоширенішим є оператор if, який може використовуватись разом з else для альтернативних гілок виконання програми.

Завдання

Завдання 1 - Програма зчитує три числа, визначає найбільше та найменше з них, після чого обчислює та виводить їх суму.

Завдання 2 - Програма зчитує значення змінної x та обчислює значення функції за умовою:
якщо x ≤ 3, використовується перша формула;
якщо x > 3, використовується друга формула.

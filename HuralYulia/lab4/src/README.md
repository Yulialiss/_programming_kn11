## Львів 2026
Мета роботи

Ознайомитися з операторами циклів мови програмування C++ та навчитися застосовувати їх для обробки масивів чисел, включаючи умовну перевірку елементів та вивід результатів на екран.

Хід роботи

Під час виконання лабораторної роботи було створено програму на C++, яка працює з масивом чотиризначних чисел та виводить ті числа, у яких сума перших двох цифр дорівнює сумі останніх двох цифр.
Для цього використовувався цикл for, який проходить по всіх елементах масиву. 
Кожне число перетворювалося на рядок через to_string, після чого здійснювалась перевірка суми цифр.
Програма виводить на екран спочатку всі числа масиву, а потім ті, які відповідають умові.
Результатом виконання програми є список чисел, що задовольняють умову, з відповідними повідомленнями на екран.
Файли з програмою розміщено у власному Git-репозиторії:
https://github.com/Yulialiss/_programming_kn11.git

## Висновки 

Виконання лабораторної роботи дозволило-
Закріпити навички роботи з циклами for для обробки масивів.
Навчитися перетворювати числа у рядки та виконувати обчислення з окремими цифрами.
Отримати практичний досвід у застосуванні умовних операторів для відбору елементів масиву.
Вивести результати на екран за допомогою cout, що допомагає перевірити правильність обчислень.
Робота сприяла закріпленню теоретичних знань про цикли та обробку масивів та набуттю практичних навичок програмування на C++.

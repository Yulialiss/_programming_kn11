# ЗВІТ

###### з виконання практичної роботи №1
###### з дисципліни “Алгоритми та структури даних”

###### Виконала:  cтудентка групи Кн-11 Марцінковська Наталя (8 варіант)
###### Перевірив: Ст. в. Квасниця Тарас Романович 

#### Дубляни 2026

###### Тема:  Блок-схеми. Базові алгоритмічні конструкції. Оцінка складності простих алгоритмів
###### Мета: Закріпити навички алгоритмічного мислення та формального опису алгоритмів. Навчитися будувати блок-схеми алгоритмів за стандартними правилами. Повторити базові алгоритмічні конструкції: послідовність, розгалуження, цикл. Навчитися оцінювати складність найпростіших алгоритмів (на рівні O(1), O(n)).
###### Опис задачі: Заданий динамічний масив довільних чисел розміром n. Вивести кількість парних та непарних елементів масиву.
###### Алгоритм: Заданємо значення n. Створюємо динамічний масив довжиною n. Циклом проходимся по всіх елементах масиву, задаючи значення кожному елементу. За допомогою умовного оператора if/else перевіряємо парність числа. Встановлені лічильники записують кількість парних та непарних значень. Виводимо їх на екран.
###### Складність алгоритму: O(N) * O(1)  = O(N)
#### Висновок: 
###### У ході виконання лабораторної роботи №1, було закріплено навички формального опису алгоритмів та алгоритмічне мислення,  за допомогою побудови блок-схеми алгоритмів. Були повторені базові алгоритмічні конструкції та розвинені навички оцінювання складності найпростіших алгоритмів.

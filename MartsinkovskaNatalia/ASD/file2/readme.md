###### Тема:  Алгоритми обробки масивів.

###### Мета:  сформувати та закріпити практичні навички розробки алгоритмів обробки масивів з урахуванням їх ефективності та вміння аналізувати алгоритми, оцінювати їх обчислювальну складність та ефективність.

###### Опис задачі: 1) Знайти середнє арифметичне всіх парних елементів масиву. 2) Додати після кожного від'ємного елемента його модуль. Якщо додавання неможливе( кількість елементів після додавання перевищить N, - максимальну кількість елементів у масиві), то вивести відповідне повідомлення. У випадку успішної операції вивести масив до та після перетворенняна екран .

###### Алгоритм: - прикріплений до звіту в гугл диску.

###### Складність алгоритму: Для завдання 1:  T(n) = n · O(1) = O(n)  M(n) = O(1) Для завдання 2:  T(n) = n + n = 2n = O(n)  M(n) = O(1)

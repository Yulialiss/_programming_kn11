# ЗВІТ

###### з виконання практичної роботи №3
###### з дисципліни “Алгоритми та структури даних”

###### Виконала:  cтудентка групи Кн-11 Марцінковська Наталя (8 варіант)
###### Перевірив: Ст. в. Квасниця Тарас Романович 

#### Дубляни 2026

###### Тема:  Числові алгоритми: НСД, НСК, алгоритм Евкліда 

###### Мета:   Ознайомитися з поняттями найбільшого спільного дільника (НСД) та найменшого спільного кратного (НСК). Вивчити класичний алгоритм Евкліда та його модифікації. Набути практичних навичок реалізації числових алгоритмів мовою C++. 

###### Опис задачі: 1. Визначити, скільки ітерацій виконує алгоритм Евкліда для заданої пари 2.Знайти пару чисел до 1000, для якої алгоритм Евкліда виконує 

###### Алгоритм: - прикріплений до звіту в гугk диск. 

#### Висновок: 
###### У ході лабораторної роботи було досліджено алгоритм Евкліда для знаходження НСД чисел та підраховано кількість його ітерацій. Також було визначено, що найбільшу кількість кроків алгоритм виконує для сусідніх чисел Фібоначчі, зокрема для пари чисел до 1000.

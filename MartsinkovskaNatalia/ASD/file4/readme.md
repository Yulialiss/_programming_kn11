###### Тема:  Розробка алгоритму лінійного пошуку, лінійного пошуку з бар’єром.

###### Мета:    Застосування алгоритму лінійного (прямого) пошуку та лінійного (прямого) пошуку з бар’єром, створення, налагодження та виконання програм, що використовують ці алгоритми.

###### Опис задачі:  Задано двовимірний масив цілих чисел A[n, n]. При обході масиву по стовпцях знайти останній додатній елемент та його координати (номер рядка та номер стовпця) .

###### Алгоритм:
###### 1. Програма починається з циклу do-while, який перевіряє, щоб введене число n (розмір матриці) було в межах від 1 до 10. 
###### 2. За допомогою двох вкладених циклів for масив arr[10][10] заповнюється випадковими числами за формулою 10 - rand() % 21 і виводиться в консоль через cout. 
###### 3. Для пошуку створюються змінні row та column зі значенням -1. 
###### 4. Наступні два цикли for обходять масив по стовпцях (зовнішній цикл по j, внутрішній по i), 
###### 5. Якщо спрацьовує умова if (arr[i][j] > 0), змінні перезаписуються поточними індексами. 
###### 6. Наприкінці оператор if-else перевіряє: якщо координати залишилися -1, виводиться текст про відсутність додатних чисел, інакше — виводиться значення елемента та його зміщені на +1 індекси.

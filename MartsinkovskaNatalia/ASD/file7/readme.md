# ЗВІТ

###### з виконання практичної роботи №7
###### з дисципліни “Алгоритми та структури даних”

###### Виконала:  cтудентка групи Кн-11 Марцінковська Наталя (8 варіант)
###### Перевірив: Ст. в. Квасниця Тарас Романович 

#### Дубляни 2026

###### Тема:  Моделювання роботи стеку та черги.

###### Мета:   закріпити знання та вміння реалізації лінійних структур даних «стек» та «черга», набути практичні навички користування подібними структурами для розв’язання прикладних задач. 

###### Опис задачі:  Сформувати масив випадкових цілих додатних чисел. Розмір масиву та діапазон чисел уводити на початку роботи програми. Написати функцію, яка за один прохід по масиву роздруковує ці числа таким чином, що спочатку роздрукуються всі парні числа, потім – усі непарні. Елементи, що дорівнюють нулю, не друкуються. Для розв’язання задачі використати чергу (на базі статичного масиву). 

###### Алгоритм: прикріплений в Google Drive.

#### Висновок: 
###### Під час виконання лабораторної роботи було досліджено та закріплено на практиці принципи організації лінійних структур даних, зокрема черги (реалізованої за принципом FIFO — First In, First Out), та алгоритми роботи з ними.

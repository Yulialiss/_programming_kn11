Варіант: №8

Необхідно створити програму, яка виводить на екран текст "Hello, World!" на мові C++. Крім того, потрібно використовувати систему контролю версій для внесення лабораторної роботи до репозиторію.

Для того щоб вивести на екран заданий текст, необхідно застосувати стандартну бібліотеку <iostream>, та розпочати написання програми з функції main(). Вкінці слід прописати рядок "return 0;".

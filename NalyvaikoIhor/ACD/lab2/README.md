### Мета роботи
Сформувати та закріпити практичні навички розробки алгоритмів обробки масивів з урахуванням їх ефективності та вміння аналізувати алгоритми, оцінювати їх обчислювальну складність та ефективність.

### Хід роботи
У ході лабораторної роботи було розроблено дві програми мовою C++ для обробки одновимірних статичних масивів.

#### Завдання 1
Розроблено алгоритм для вибору підмножини елементів масиву:
* Програма генерує масив випадкових чисел у заданому діапазоні.
* Здійснюється пошук індексів мінімального та максимального елементів масиву.
* Реалізовано виведення на екран елементів, що розташовані у проміжку між знайденими індексами.

#### Завдання 2
Розроблено програму для модифікації структури масиву шляхом вставки нових елементів:
* Програма ідентифікує всі парні елементи у вихідному масиві.
* Реалізовано алгоритм зсуву елементів вправо для звільнення місця під нові дані.
* Після кожного парного числа вставляється його квадрат.
* Додано перевірку на переповнення статичного масиву (N=100).

### Висновки
Під час виконання роботи було опановано базові методи обробки масивів: пошук екстремальних значень та алгоритми вставки елементів із переміщенням даних.
Оцінено часову складність алгоритмів: для першого завдання — O(n), для другого — O(n²) у найгіршому випадку. Додаткові витрати пам'яті складають O(1).

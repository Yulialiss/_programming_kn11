### Мета роботи
Ознайомитися з поняттями найбільшого спільного дільника (НСД) та найменшого спільного кратного (НСК). Вивчити класичний алгоритм Евкліда та набути навичок реалізації числових алгоритмів.

### Хід роботи
У ході лабораторної роботи було реалізовано:
1. **Алгоритм Евкліда (з остачею)** для пошуку НСД двох чисел. Складність алгоритму: $O(\log(\min(a, b)))$.
2. **Функцію пошуку НСД для масиву**, що працює шляхом послідовного обчислення НСД.
3. **Алгоритм перевірки умови збільшення НСД**: програма по черзі "видаляє" кожен елемент масиву та перевіряє, чи стане НСД решти елементів більшим за початковий.

### Результати тестування
*   **Вхідні дані:** `[12, 24, 36, 5]`
*   **Початковий НСД:** `1`
*   **Результат:** Якщо видалити `5`, НСД решти елементів збільшиться до `12`.

### Висновки
Під час виконання роботи було опановано числові алгоритми. Встановлено, що видалення "аномального" числа з масиву (яке не має спільних дільників з іншими) може значно підвищити спільний дільник решти послідовності.

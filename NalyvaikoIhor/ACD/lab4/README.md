### Мета роботи
Навчитися користуватися лінійним пошуком у двовимірних масивах.

### Хід роботи
У ході роботи було розроблено програму для пошуку першого нуля в матриці.
1. Створено матрицю A[5][5].
2. Заповнено її випадковими числами.
3. Реалізовано пошук по рядках.
4. Виведено координати першого нульового елемента.

### Висновки
Опановано пошук у двовимірних структурах даних. Складність алгоритму для матриці $n \times n$ становить $O(n^2)$.

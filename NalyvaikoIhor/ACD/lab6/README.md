### Мета роботи
Навчитися розробляти та реалізовувати алгоритми з використанням рекурсії.

### Опис алгоритму
Алгоритм базується на математичній залежності $n^2 = (n-1)^2 + 2(n-1) + 1$. 
1. Якщо число дорівнює 0, повернути 0.
2. Якщо число більше 0, викликати функцію для (n-1), додати до результату $2(n-1)$ та 1.
3. Для від'ємних чисел використовувати їх модуль.

### Тестові дані
* **Вхід:** `4`
* **Обчислення:** `recursiveSquare(3) + 2*3 + 1` -> `9 + 6 + 1 = 16`
* **Результат:** `16`

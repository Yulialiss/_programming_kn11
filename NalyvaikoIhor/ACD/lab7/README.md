# Звіт до лабораторної роботи №7
## Тема: Моделювання роботи стеку та черги
**Виконав:** студент групи КН-11 Наливайко Ігор
**Варіант:** №10 (Перевірка симетричності рядка відносно символу '*')

### Мета роботи
Закріпити знання та вміння реалізації лінійної структури даних «стек», набути практичні навички користування такою структурою для розв'язання прикладних задач.

### Опис алгоритму
1. Програма зчитує вхідний рядок та перевіряє наявність рівно одного символу '*'.
2. Усі символи, що стоять ліворуч від '*', послідовно додаються у стек (операція `Push`).
3. Після зустрічі '*' програма починає зчитувати символи праворуч від неї.
4. Для кожного правого символу виконується вилучення елемента з верхівки стека (операція `Pop`).
5. Оскільки стек працює за принципом LIFO (Last In - First Out), символи вилучаються у зворотному порядку. Якщо всі вилучені символи збігаються з відповідними символами правої частини, рядок вважається симетричним.

### Тестові дані
* **Вхід:** `abc*cba`
* **Очікуваний результат:** Рядок симетричний (Symmetric).
* **Вхід:** `abc*dca`
* **Очікуваний результат:** Рядок несиметричний (Not symmetric).

### Висновки
Опановано роботу зі стеком на базі статичного масиву. Стек є ефективною структурою для задач, де потрібен доступ до даних у зворотному порядку. Складність основних операцій (`Push`, `Pop`) становить $O(1)$.

Мета роботи

Навчитися використовувати вказівники при написанні програм на мові C++, опанувати навички роботи з адресами об'єктів у пам'яті та динамічним виділенням ресурсів.

Хід роботи

У ході лабораторної роботи було розроблено дві програми з використанням вказівників для обробки тексту.

 Завдання 1

Розроблено алгоритм для роботи з динамічним рядком.
Програма зчитує речення та за допомогою вказівника здійснює прохід по символах.

Реалізовано підрахунок кількості слів, що починаються з літери 'a'.
Доступ до символів здійснюється через розіменування вказівника (*ptr).

Завдання 2

Розроблено програму для маніпуляції літерами в слові.

Створено масив вказівників на літери (new char*[n])
Виконано сортування вказівників за кодами літер
Виведено результат через розіменування вказівників
Звільнено динамічну пам'ять (delete[])
Висновки

Під час виконання роботи було опановано навички роботи з вказівниками у C++, зокрема використання операцій взяття адреси (&) та розіменування (*).

Отримано знання щодо динамічних масивів вказівників та маніпуляції даними без їх переміщення в пам'яті.

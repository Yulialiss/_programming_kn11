# Лабораторна робота 2 — Обчислення функції F(x)

Опис
-
Невелика програма на C++, яка обчислює значення функції

F(x) =
- sin(x), якщо x <= 0
- cos(x), якщо x > 0

Файли
-
- `task2(1).cpp` — реалізація програми (ввід числового `x`, обчислення і вивід `F(x)`).
- `task2(2).cpp` — та ж програма (дубль у проекті).

Завдання
-
1. Ознайомитися з кодом програми.
2. Скомпілювати один з файлів і запустити програму.
3. Перевірити роботу для різних значень `x` (від'ємні, нуль, додатні).

Компіляція і запуск (Windows, MinGW / g++)
-
Компілювання:

```bash
g++ "task2(1).cpp" -o task2_1.exe
g++ "task2(2).cpp" -o task2_2.exe
```

Запуск:

```powershell
.\task2_1.exe
.\task2_2.exe
```

Приклад використання
-
Ввід:

```
Enter x : -1
```

Очікуваний вивід (приблизно):

```
F(x) = -0.841471
```

Примітки
-
- Обидва файли реалізують ту саму логіку; відмінності в іменах файлів лише для зручності.
- Програма використовує функції `sin` і `cos` з `<cmath>` та читає значення `x` з стандартного вводу.

## Львів 2026
Мета роботи

Ознайомитися з операторами циклів мови програмування C++ та навчитися застосовувати їх для обробки масивів чисел, включаючи пошук екстремальних значень (мінімуму та максимуму), умовну перевірку елементів та їх трансформацію.

Хід роботи
Під час виконання лабораторної роботи було розроблено програму на мові C++, що складається з двох основних частин (завдань):
Завдання 1: Табулювання функції та обчислення добутку.
    Реалізовано введення параметрів a (початок), b (кінець) та h (крок) для дослідження функції $ = x \cdot \sin^2(x) + 1
    Використано цикл for для проходження по всьому інтервалу з заданим кроком.
    Для обчислення математичних значень використано бібліотеку <cmath>, зокрема функцію pow().
    Впроваджено логіку накопичення добутку лише для тих значень $y$, які задовольняють умові y > 1.
    Результати виведено у вигляді таблиці для зручності аналізу.
Завдання 2: Обчислення складної суми (вкладені цикли).
    Реалізовано обчислення суми $S$, де кожен доданок є результатом внутрішнього циклу (добутку послідовних чисел від $i$ до $2i$).
    Для запобігання переповненню пам'яті при роботі з великими числами використано тип даних long long.
    Продемонстровано навички роботи з вкладеними циклічними структурами.

## Висновки 

Виконання роботи дало змогу опанувати використання циклічних операторів для розв'язання математичних задач. Було засвоєно методику табулювання функцій та форматованого виводу результатів у консоль. Практично опрацьовано роботу з вкладеними циклами та накопиченням результатів обчислень. Набуто навичок використання математичних функцій бібліотеки cmath та вибору відповідних типів даних для запобігання переповненню пам'яті. Отримано досвід у реалізації логічних перевірок усередині циклів для вибіркової обробки даних.

## Львів 2026
Мета роботи

Ознайомитися з операторами циклів мови програмування C++ та навчитися застосовувати їх для обробки масивів чисел, включаючи пошук екстремальних значень (мінімуму та максимуму), умовну перевірку елементів та їх трансформацію.

Хід роботи

Під час виконання лабораторної роботи було створено програму на C++, яка працює з масивом дійсних чисел.
Згідно з індивідуальним завданням, програма реалізує таку логіку обробки:
Знаходить найменший та найбільший елементи введеної послідовності.
Проходить по масиву за допомогою циклу for.
Якщо елемент масиву $a_k \ge 0$, він множиться на квадрат найменшого елемента.
Якщо елемент масиву $a_k < 0$, він множиться на квадрат найбільшого елемента.
Програма виводить на екран початковий стан масиву та результат після виконання математичних операцій.
Файли з програмою розміщено у власному Git-репозиторії.

## Висновки 

Виконання лабораторної роботи дозволило:
Закріпити навички роботи з одновимірними масивами та циклами для їх обробки.
Навчитися реалізовувати алгоритми пошуку мінімального та максимального значень у масиві.
Отримати практичний досвід застосування складних умовних операторів для модифікації даних за заданою формулою.
Вдосконалити навички роботи з потоками введення-виведення (cin, cout) для взаємодії з користувачем.

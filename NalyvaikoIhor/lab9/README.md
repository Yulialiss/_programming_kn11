Мета роботи

Вивчити методи роботи з текстовими файлами у мові C++ та реалізувати програму для запису, зчитування та обробки текстових даних.

Хід роботи

Розроблено програму, яка працює з двома текстовими файлами.

На першому етапі створюється файл text_1.txt, у який записуються символьні рядки довільної довжини. Слова у рядках можуть бути розділені пробілами та різними розділовими знаками.

На другому етапі програма зчитує вміст файлу text_1.txt, знаходить у кожному рядку всі входження заданого слова та вилучає їх. Отримані результати записуються у новий файл text_2.txt.

На третьому етапі програма зчитує файл text_2.txt та виводить його вміст по рядках на екран.

Висновки

Під час виконання роботи було опановано навички роботи з файлами у мові C++, зокрема запис, зчитування та обробку текстової інформації.

Отримано практичні знання щодо пошуку та видалення підрядків у тексті, а також організації взаємодії між файлами.

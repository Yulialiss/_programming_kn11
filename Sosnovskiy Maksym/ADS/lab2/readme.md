# Лабораторна робота №2: Алгоритми обробки масивів

**Варіант:** 13  
**Завдання:** Знайти суму елементів з непарними індексами, що розташовані перед першим від’ємним елементом масиву.

## Аналіз складності
* **Часова складність:** $O(n)$, оскільки ми проходимо по масиву максимум два рази (для пошуку від'ємного елемента та для розрахунку суми).
* **Просторова складність:** $O(n)$ для зберігання масиву в динамічній пам'яті.

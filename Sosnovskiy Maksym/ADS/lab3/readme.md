# Лабораторна робота №3: Числові алгоритми

**Варіант:** 13  
**Завдання:** Обчислити суму $N$ дробів та вивести результат у нескоротному вигляді (використовуючи алгоритм Евкліда).

## Аналіз складності
* **Алгоритм Евкліда:** $O(\log(\min(a, b)))$.
* **Загальна складність:** $O(N \cdot \log(M))$, де $N$ — кількість дробів, а $M$ — значення чисельника чи знаменника. Це дуже ефективний алгоритм для роботи з числами.

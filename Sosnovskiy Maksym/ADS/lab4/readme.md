# Лабораторна робота №4: Розробка алгоритму лінійного пошуку

**Варіант:** 13  
**Завдання:** Задано двовимірний масив цілих чисел $A[n,n]$. При обході масиву по стовпцях знайти останній від'ємний елемент та його координати.

## Аналіз складності
* **Часова складність:** $O(n^2)$, оскільки алгоритм перевіряє кожен елемент квадратної матриці розміром $n \times n$.
* **Просторова складність:** $O(n^2)$ для зберігання матриці в пам'яті.

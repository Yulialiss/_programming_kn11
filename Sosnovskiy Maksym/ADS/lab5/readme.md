# Лабораторна робота №5: Аналіз методів сортування

**Варіант:** 13  
**Завдання:** Написати алгоритм сортування методом вибірки (Selection Sort) у порядку зростання та дослідити його складність.

## Аналіз складності
* **Найгірший випадок (Worst case):** $O(n^2)$
* **Найкращий випадок (Best case):** $O(n^2)$
* **Середній випадок (Average case):** $O(n^2)$
* **Просторова складність:** $O(1)$ (сортування виконується на місці).

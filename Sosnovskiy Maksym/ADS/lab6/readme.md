# Лабораторна робота №6: Розробка рекурсивних алгоритмів

**Варіант:** 13  
**Завдання:** Розробити рекурсивний алгоритм для обчислення значень за заданою формулою та порівняти його з ітераційним підходом.

## Аналіз складності
* **Часова складність:** $O(2^n)$ для простої рекурсії з двома викликами (без мемоїзації).
* **Просторова складність:** $O(n)$ через глибину стека викликів.

# Лабораторна робота №7: Моделювання роботи стеку та черги

**Варіант:** 13  
**Завдання:** Реалізувати перевірку правильності розстановки дужок у символьному рядку за допомогою структури даних "Стек".

## Аналіз складності
* **Часова складність:** $O(n)$, де $n$ — кількість символів у рядку (один прохід).
* **Просторова складність:** $O(n)$ у найгіршому випадку (якщо всі символи — дужки, що відкриваються).
* **Операції стека:** Кожна операція `push` та `pop` має складність $O(1)$.

## Опис роботи
У цій лабораторній роботі реалізовано консольну програму мовою C++, яка виконує базові операції введення та виведення даних. Програма зчитує з клавіатури ім’я, прізвище студента та номер варіанту, після чого виводить оформлений заголовок роботи та привітання. 

Робота спрямована на:
* Ознайомлення з базовим синтаксисом мови C++.
* Вивчення операторів `cin` та `cout`.
* Налаштування структури проєкту згідно з методичними вказівками.
* Роботу з системою контролю версій Git та публікацію коду на GitHub.

## Структура проєкту
* `src/main.cpp` — вихідний код програми.
* `README.md` — опис лабораторної роботи.

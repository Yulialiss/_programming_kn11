## Опис роботи
Ця лабораторна робота є фінальною та присвячена роботі з файловою системою в C++. Програма демонструє створення текстового файлу, запис у нього структурованих даних (ім'я студента, група, варіант) та подальше зчитування цих даних для виводу в консоль.

Робота спрямована на:
* Вивчення бібліотеки `<fstream>` для роботи з файлами.
* Розуміння різниці між вхідними (`ifstream`) та вихідними (`ofstream`) потоками.
* Обробку помилок при відкритті файлів.
* Повне завершення структури навчального репозиторію.

## Project Structure
* `src/main.cpp` — вихідний код програми.
* `README.md` — опис лабораторної роботи.

## How to run
1. Compile: `g++ src/main.cpp -o lab10`
2. Run: `./lab10`

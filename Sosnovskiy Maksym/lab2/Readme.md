## Опис роботи
У цій лабораторній роботі реалізовано програму на мові C++, яка перевіряє наявність хоча б однієї пари рівних чисел серед трьох введених значень.

Робота спрямована на:
* Вивчення базових типів даних у C++.
* Роботу з умовним оператором `if-else`.
* Використання логічних операторів (АБО — `||`).
* Оформлення структури проєкту на GitHub.

## Project Structure
* `src/main.cpp` — вихідний код програми.
* `README.md` — опис лабораторної роботи.

## Опис роботи
У цій лабораторній роботі реалізовано програму на мові C++ для обчислення значень математичної функції з використанням циклів. Програма проходить по заданому діапазону значень від 0 до 2 з кроком 0.2.

Робота спрямована на:
* Вивчення циклічних конструкцій (`for`, `while`).
* Роботу з математичною бібліотекою `<cmath>`.
* Форматування виводу даних за допомогою `<iomanip>`.
* Закріплення навичок структурування проєктів.

## Project Structure
* `src/main.cpp` — вихідний код програми.
* `README.md` — опис лабораторної роботи.

## How to run
1. Compile: `g++ src/main.cpp -o lab3`
2. Run: `./lab3`

## Опис роботи
У цій лабораторній роботі реалізовано програму на мові C++ для роботи з одновимірними масивами. Програма дозволяє користувачу ввести 5 цілих чисел, зберігає їх у масиві, обчислює їхню суму та середнє арифметичне значення.

Робота спрямована на:
* Вивчення синтаксису оголошення та ініціалізації масивів.
* Роботу з циклами для ітерації по елементах масиву.
* Виконання базових арифметичних операцій над набором даних.
* Закріплення навичок структурування проєктів на GitHub.

## Project Structure
* `src/main.cpp` — вихідний код програми.
* `README.md` — опис лабораторної роботи.

## How to run
1. Compile: `g++ src/main.cpp -o lab4`
2. Run: `./lab4`

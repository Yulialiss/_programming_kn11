## Опис роботи
У цій лабораторній роботі реалізовано програму на мові C++ для роботи з двовимірними масивами (матрицями). Програма дозволяє ввести елементи матриці розміром 3x3 та обчислює суму чисел, що знаходяться на головній діагоналі.

Робота спрямована на:
* Вивчення синтаксису оголошення двовимірних масивів.
* Використання вкладених циклів `for` для обробки табличних даних.
* Роботу з індексами матриці та форматуванням виводу (`setw`).
* Дотримання структури репозиторію на GitHub.

## Project Structure
* `src/main.cpp` — вихідний код програми.
* `README.md` — опис лабораторної роботи.

## How to run
1. Compile: `g++ src/main.cpp -o lab5`
2. Run: `./lab5`

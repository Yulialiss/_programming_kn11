## Опис роботи
У цій лабораторній роботі реалізовано програму на мові C++ для роботи з текстовими рядками. Програма приймає на вхід прізвище користувача, обробляє його за допомогою бібліотеки `<string>` та виводить кількість символів у введеному слові.

Робота спрямована на:
* Ознайомлення з типом даних `std::string`.
* Вивчення базових методів роботи з рядками (наприклад, `.length()`).
* Роботу з потоками введення/виведення для тексту.
* Оформлення документації проєкту на GitHub.

## Project Structure
* `src/main.cpp` — вихідний код програми.
* `README.md` — опис лабораторної роботи.

## How to run
1. Compile: `g++ src/main.cpp -o lab7`
2. Run: `./lab7`

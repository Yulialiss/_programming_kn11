## Опис роботи
У цій лабораторній роботі реалізовано програму на мові C++ з використанням структур (`struct`). Це дозволяє групувати пов'язані дані різних типів в одну логічну одиницю. У програмі створено структуру "Студент" з полями для імені, номера групи та середнього балу.

Робота спрямована на:
* Вивчення синтаксису оголошення структур.
* Роботу з полями структур через оператор "крапка" (`.`).
* Організацію складних типів даних.
* Закріплення навичок ведення репозиторію на GitHub.

## Project Structure
* `src/main.cpp` — вихідний код програми.
* `README.md` — опис лабораторної роботи.

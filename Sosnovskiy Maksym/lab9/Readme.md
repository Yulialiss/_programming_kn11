## Опис роботи
У цій лабораторній роботі реалізовано програму на мові C++ для вивчення роботи з вказівниками. Програма демонструє, як отримати адресу змінної в пам'яті та як змінити значення цієї змінної, звертаючись безпосередньо до її адреси.

Робота спрямована на:
* Розуміння концепції вказівників та адрес пам'яті.
* Вивчення операторів взяття адреси (`&`) та розіменування (`*`).
* Роботу з типами даних, що вказують на інші типи.
* Закріплення структури репозиторію на GitHub.

## Project Structure
* `src/main.cpp` — вихідний код програми.
* `README.md` — опис лабораторної роботи.

## How to run
1. Compile: `g++ src/main.cpp -o lab9`
2. Run: `./lab9`

## Мета:
Ознайомитися з алгоритмами обробки одновимірних масивів у мові програмування C++, навчитися реалізовувати меню для взаємодії з користувачем, виконувати базові операції над масивами, а також аналізувати складність алгоритмів і обсяг використаної пам’яті.

## Хід роботи

1. Створення масиву
У програмі я використовую статичний масив розміром 100 елементів. Фактична кількість елементів зберігається у змінній n.

2. Заповнення масиву
Користувач вводить: кількість елементів n та межі діапазону випадкових чисел A та B. Масив заповнюється випадковими числами за формулою a[i] = A + rand() % (B - A + 1).

3. Виведення масиву
Програма виводить елементи масиву, якщо він не є порожнім.

4. Виконання завдання №1
Знаходимо кількість додатних непарних елементів та їх суму.

5. Виконання завдання №2
Видаляємо елементи з парними індексами (0, 2, 4, ...) та зсуваємо елементи масиву без пропусків.

6. Блок-схеми
Для кожного завдання алгоритму будуємо блок-схему, яка буде відповідати умові завдання.

7. Використані алгоритмічні структури
Визначу, які базові алгоритмічні структури використав у коді.

8. Оцінка складності алгоритмів та пам'яті
Аналізую та оцінюю складність алгоритму та його пам'ять.

3. Виконав аналіз та модифікацію масиву.
5. Побудував блок-схеми для кожного з завдань алгоритму.
6. Описав використані алгоритмічні структури.
7. Оцінив часову та просторову складності алгоритмів.

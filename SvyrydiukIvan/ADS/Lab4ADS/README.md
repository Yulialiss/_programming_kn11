## Мета:
Метою лабораторної роботи є закріплення навичок розробки алгоритмів для обробки двовимірних масивів,а саме реалізації пошуку елементів за заданою умовою, та виконання операцій обміну знайдених елементів.

## Хід роботи

1. Побудова алгоритму для відведеного коду
Перед програмою створю код для неї, що буде покроково описувати роботу майбутнього коду.

2. Ввід розмірності матриці
На початку програми користувач вводить розмірність квадратної матриці n, яка визначає кількість рядків і стовпців.

2. Створення динамічної матриці
Для зберігання даних використаємо бібліотеку <vector>. Це дозволить створити динамічну квадратну матрицю розміру n×n.

3. Заповнення матриці
Матриця заповнюється випадковими цілими числами у заданому діапазоні та одразу виводиться на екран у вигляді таблиці.

4. Робота з бічною діагоналлю
Бічна діагональ визначається як A[i][n - 1 - i]. Спочатку на ній здійснюється лінійний пошук першого додатного елемента, а потім пошук останнього від’ємного.

5. Обмін елементів та вивід результату
Після знаходження двох елементів ми виконуємо їх обмін місцями за допомогою допоміжної змінної. Після обміну програма виводить оновлену матрицю на екран.

## Висновок
У ході виконання лабораторної роботи я:
1. Навчився створювати алгоритми лінійного пошуку та будувати по ним код програми.
2. Реалізував створення та заповнення квадратної матриці розміру nхn.
3. Закріпив роботу з бічною діагоналлю матриці.
4. Запрограмував лінійний пошук першого додатного та останнього від’ємного елементів.
5. Виконав обмін знайдених елементів.

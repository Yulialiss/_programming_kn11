## Мета:
Ознайомитися з алгоритмом сортування вибіркою, навчитися його програмній реалізації мовою C++, а також виконати аналіз часової та просторової складності алгоритму.

## Хід роботи

1. Побудова алгоритму для сортування вибіркою
Спочатку ми створюємо алгоритм сортування вибіркою. Його основна ідея полягає у послідовному виборі найменшого елемента з невідсортованої частини масиву та перестановці його на правильну позицію.

2. Реалізація алгоритму на C++
Було реалізовано програму мовою C++, яка: зчитує кількість елементів масиву; виконує сортування методом вибірки; виводить початковий та відсортований масиви.

3. Аналіз складності алгоритму
Визначаємо часову та просторову складності алгоритму.

4. Побудова блок-схеми
Для алгоритму сортування вибіркою побудую блок-схему, яка відображає: ініціалізацію масиву; пошук мінімального елемента; обмін елементів та повторення циклу до завершення сортування.

5. Тестування програми
Проведу кілька контрольних тестувань програми, щоб переконатися у її правильності.

## Висновок
У ході виконання лабораторної роботи було:
1. Реалізовано алгоритм сортування вибіркою мовою C++.
2. Описано його основні етапи роботи.
3. Проведено аналіз часової складності O(n^2) та просторової складності O(1).
4. Побудовано блок-схему алгоритму.
5. Виконано тестування програми на різних наборах даних.

## Мета:
Ознайомлення з принципами побудови рекурсивних алгоритмів, набуття навичок їх реалізації мовою програмування C++, а також застосування рекурсії для розв’язання задач, перевірки властивостей чисел.

## Хід роботи

1. Побудова рекурсивного алгоритму
На першому етапі було розроблено покроковий алгоритм перевірки числа на ступінь числа 3, який передбачає рекурсивне ділення числа та перевірку базових умов завершення.

2. Створення основного проєкту
Було створено програмний проєкт мовою C++, у якому реалізовано головну функцію та рекурсивну функцію перевірки.

3. Реалізація коду
Реалізовано функцію PowerOfThree, яка перевіряє, чи є число степенем трійки шляхом послідовного ділення числа на 3. У головній функції здійснюється введення числа, виклик рекурсивної функції та виведення результату перевірки.

4. Побудова блок-схеми
Для реалізованого алгоритму побудовано блок-схему, яка відображає: перевірку базового випадку; рекурсивне ділення на 3; виведення результату.

## Висновок
У ході виконання лабораторної роботи я:
1. Ознайомився з принципами побудови рекурсивних алгоритмів.
2. Реалізував рекурсивну функцію для перевірки числа на ступінь трійки.
3. Закріпив навички роботи з умовами базового випадку та рекурсивного виклику.
4. Розробив алгоритм та блок-схему роботи програми.

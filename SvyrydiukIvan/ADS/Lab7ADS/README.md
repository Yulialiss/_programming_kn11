## Мета:
Ознайомитися з принципами роботи лінійних структур даних (стек і черга), навчитися реалізовувати стек в мові C++, а також застосовувати його для розв’язання прикладної задачі — перевірки рядка на паліндром.

## Хід роботи

1. Створення структури стеку
Оголошено структуру Stack на основі статичного масиву та реалізовано основні операції: додавання елемента (Push); видалення елемента (Pop); визначення розміру; виведення елементів.

2. Реалізація інтерфейсу роботи зі стеком
Створено меню користувача. Реалізовано циклічну взаємодію з програмою. Додано обробку помилок.

3. Реалізація задачі перевірки паліндрому
Реалізовано функцію перевірки рядка на паліндром. Виконано наступні дії: введення рядка, видалення пробілів, запис символів у стек, порівняння символів з початку рядка та зі стеку.

4. Алгоритм роботи паліндрому
Створено покрокову логіку: заповнення стеку; посимвольне порівняння; визначення результату.

5. Побудова блок-схеми
У кінці роботи побудував блок-схему для алгоритму перевірки паліндрому.

## Висновок
У ході виконання лабораторної роботи я:
1. Ознайомився з принципами роботи стеку як структури даних.
2. Реалізував стек на основі статичного масиву в C++.
3. Навчився використовувати операції Push та Pop.
4. Реалізував прикладне застосування стеку для перевірки паліндрому.
5. Закріпив навички побудови алгоритмів та блок-схем для структур даних.

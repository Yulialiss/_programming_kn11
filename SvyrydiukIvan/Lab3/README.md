## Мета:
Ознайомитися з використанням циклів та їх видами в мові програмування C++ і навчитися обчислювати складніші математичні вирази за їх допомогою.

## Хід роботи

1. Створив програму для обчислення значень певної функції (y = tan(2*x) - 3) у заданому проміжку [a; b] з кроком h та певного числа x (x = x - x^3/3! + x^5/5! - x^7/7! + x^9/9! - x^11/11! + x^13/13!).

2. Використав цикл for для послідовного перебору значень x та обчислення y.

3. Ознайомився під час циклу з використанням максимального та мінімального значення функції.

4. Навчився реалізовувати дані у вигляді найпростішої таблиці.

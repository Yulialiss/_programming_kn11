## Мета:
Навчитися працювати з двовимірними масивами (матрицями) у C++, використовувати умовні оператори, знаходити максимальні елементи на діагоналях та виконувати обмін елементів матриці.
## Хід роботи
1. Вводжу розмір матриці.
Користувач вводить непарне число, яке визначає розмір квадратної матриці. Програма перевіряє умову непарності і зупиняє виконання, якщо умова не виконана.

2. Вводжу елементи матриці.
Користувач поступово вводить всі елементи матриці. Дані зберігаються у двовимірному масиві matrix[n][n].

3. Визначаю центральний елемент.
Центральний елемент обчислюється за формулою center = n / 2. Це дозволяє знайти елемент, який розташований у середині матриці.

4. Шукаю максимальний елемент на діагоналях.
Перевіряються всі елементи головної (matrix[i][i]) та бічної (matrix[i][n-i-1]) діагоналей. Зберігаються координати та значення найбільшого елемента.

5. Виконую обмін максимального елемента з центральним.
Виконується обмін значень центрального елемента та максимального елемента з діагоналей. Для цього використовується тимчасова змінна temp.

6.Виведення оновленої матриці.
Програма виводить матрицю після обміну, щоб користувач побачив результат.
## Висновок
У ході виконання роботи я:
1. Навчився працювати з двовимірними масивами у C++.

3. Освоїв роботу з головною та бічною діагоналями матриці.
4. Навчився визначати центральний елемент матриці.
5. Отримав практичні навички обміну елементів матриці та виведення результатів.

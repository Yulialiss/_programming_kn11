## Мета:
Навчитися працювати з вказівниками та посиланнями у мові програмування C++. Узагальнити їх використання для отримання доступу до елементів рядків, виконання обробки тексту та аналізу символів.

## Хід роботи

Завдання №1
1. Введення даних
Користувач вводить розмір рядка та сам рядок символів.

2. Створення динамічного масиву
У програмі я виділяю пам’ять для зберігання рядка за допомогою вказівника.

3. Використання вказівника
Створюю додатковий вказівник для проходження по рядку.

4. Перевірка умови
Програма перевіряє, чи є в рядку символ 'S', після якого через один символ знаходиться '1'.

5. Виведення результату
Якщо умова виконується, то виводиться повідомлення, а якщо ні, то повідомлення про невиконання раніше поставленої умови.

6. Звільнення пам’яті
Після завершення роботи з програмою звільняється динамічна пам’ять.

Завдання №2
1. Введення тексту
Користувач вводить рядок символів чи текст.

2. Створення масиву вказівників
Я оголошую масив вказівників для збереження адрес знаків пунктуації.

3. Пошук пунктуації
Потім програма проходить по тексту та знаходить символи: '.', ',', '!', '?'.

4. Збереження позицій
Адреси знайдених символів записуються у масив вказівників.

5. Обробка результатів
Програма бере кожні два сусідні знаки пунктуації.

6. Виведення частин тексту
У результаті виводяться частини тексту від одного знака пунктуації до наступного.

## Висновок
У ході виконання лабораторної роботи я:
1. Навчився працювати з вказівниками та посиланнями у C++.
2. Закріпив навички роботи з рядками та символами з використанням вказівників та посилань.
3. Освоїв динамічне виділення пам’яті.
4. Навчився використовувати масиви вказівників.
5. Зрозумів принцип обробки текстових даних за допомогою вказівників та посилань.

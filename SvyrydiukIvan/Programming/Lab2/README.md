## Мета:
Ознайомитися з використанням типів даних та умовних операторів в мові програмування C++ і навчитися обчислювати математичні вирази за їх допомогою.

## Хід роботи

1. Детальніше ознайомився з різними бібліотеками та видами типів даних.

2. Реалізував програму для визначення точки, яка знаходиться ближче до початку координат.

3. Ознайомився з умовними операторами if/else в мові програмування C++.

4. Реалізував найпростішу програму для обчислення функції з розгалуженням, використовуючи математичні функції з бібліотеки <cmath>.

## Висновок

У ході виконання лабораторної роботи я:
1. Ознайомився з умовними операторами в C++.
2. Навчився використовувати математичні функції з бібліотеки <cmath>.
3. Закріпив навички роботи з змінними типу float, double.
4. Навчився розв'язувати задачі з розгалуженням.
5. Отримав практичні навички написання програм на C++.

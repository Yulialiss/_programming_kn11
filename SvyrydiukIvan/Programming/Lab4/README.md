## Мета:

Ознайомитися з використанням одновимірних масивів та їх заданням в мові програмування C++ і навчитися створювати програми за їх допомогою.

## Хід роботи

1. Оголосили змінну a для введення кількості чисел.
2. Створили масив numbers\[50] для зберігання введених чисел.
3. За допомогою циклу for ввели a чисел у масив.
4. Визначили змінну min як перший елемент масиву (numbers\[0]).
5. За допомогою циклу перевірили всі елементи масиву з непарними індексами (1, 3, 5…) і знайшли мінімальне значення серед них.
6. Вивели знайдене мінімальне число на екран.

## Висновок

У ході виконання лабораторної роботи я:

1. Створив програму на мові C++, яка вводить числа в масив і дозволяє працювати з його елементами.
2. Відпрацював навички використання циклів для обробки всіх елементів масиву.
3. Використав умовний оператор для перевірки парності індексів та визначення мінімального числа серед елементів з непарними індексами.
4. Закріпив вміння правильно задавати та використовувати змінні для збереження результатів обчислень.

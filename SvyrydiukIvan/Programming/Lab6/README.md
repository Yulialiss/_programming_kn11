## Мета:
Навчитися створювати та використовувати функції у мові програмування C++, передавати параметри у функції та повертати значення з функцій.
## Хід роботи
1. Вводжу початкові дані.
На початку програми я ввів значення сторін трикутника a, b, c з клавіатури.
2. Реалізація функції для обчислення.
Я створив окрему функцію, яка обчислює значення за заданою формулою.
Функція приймає три параметри та повертає результат обчислення.
3. Використання функції в програмі.
Дану функцію я викликав кілька разів, підставляючи різні значення аргументів.
Таким чином отримав кілька результатів обчислень.
4. Обробка отриманих результатів.
Отримані значення я зберіг у змінних для подальшого використання в програмі.
5. Шукаю найбільше значення.
Для визначення найбільшого значення я створив окрему функцію, яка порівнює кілька чисел за допомогою умовних операторів.
6. Виведення результатів.
На завершення програма виводить усі отримані результати та найбільше значення на екран.
## Висновок
У ході виконання лабораторної роботи я:
1. Навчився створювати користувацькі функції у C++.
2. Закріпив передачу параметрів у функції.
3. Навчився повертати значення з функцій.
4. Зрозумів принцип повторного використання функцій.
5. Отримав практичні навички структурування програми за допомогою функцій.

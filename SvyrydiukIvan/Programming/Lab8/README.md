## Мета:
Навчитися створювати та використовувати структури у мові програмування C++, зберігати в них пов’язані дані, працювати з масивами структур, виконувати обчислення та сортування елементів.
## Хід роботи
1. Оголошення структури
На початку програми я створив структуру Triangle, яка містить три сторони трикутника (a, b, c) та додаткове поле для збереження його номера (id).
2. Введення даних
Користувач вводить кількість трикутників, після чого в програму вводяться значення сторін кожного трикутника.
3. Перевірка правильності трикутника
Для кожного трикутника виконується перевірка існування за умовою: сума будь-яких двох сторін повинна бути більшою за третю.
4. Обчислення характеристик
Для кожного правильного трикутника обчислюються периметр, площа (за формулою Герона).
5. Пошук найбільшого трикутника за площею
Програма знаходить трикутник з найбільшою площею серед усіх правильних трикутників.
6. Сортування трикутників
Виконується сортування масиву структур за зростанням периметра методом обміну (bubble sort).
7. Виведення результатів
На екран виводиться трикутник з найбільшою площею, список трикутників у порядку зростання периметра, повідомлення про неправильні трикутники (якщо такі є).

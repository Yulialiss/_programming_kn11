## Хід роботи

Завдання №1
1. Введення даних
Спочатку користувач повинен вводити текст построково. Введення завершується порожнім рядком, а дані записуються у файл text_1.txt.

2. Обробка тексту
Програма зчитує файл посимвольно та формує слова, використовуючи тільки літери англійського алфавіту.

3. Групування слів
Слова групуються за довжиною (від 1 до 16 символів) та зберігаються у масиві.

4. Виведення результатів
Результати записуються у файл text_2.txt та виводяться на екран.

Завдання №2
1. Оголошення структури
На початку програми створюємо структуру Car, яка містить такі поля: brand (марка автомобіля), number (номер автомобіля), color (колір), year (рік випуску), owner (власник), address (адреса).

2. Додавання даних
Користувач вводить дані про автомобіль, після чого вони записуються у файл cars.txt.

3. Виведення даних
Програма зчитує всі записи з файлу та виводить їх у нашу консоль.

4. Зміна даних
Користувач вводить номер автомобіля. Якщо запис знайдено, можна змінити колір автомобіля і після цього файл перезаписується.

5. Пошук даних
Однією з функцій, що виконує програма є пошук автомобілів за кольором і перевірка чи номер починається з "77". У результаті виводяться дані про власника та адресу.

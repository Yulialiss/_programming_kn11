# Звіт
про виконання лабораторної роботи №1 з дисципліни «Алгоритми та структури даних» на тему «Блок-схеми. Оцінка складності простих алгоритмів»

Виконав: студент групи КН-11 Свиридюк Вадим

Прийняв: ст. викладач Т. Квасниця

## Дубляни 2026

Мета роботи: Ознайомитися з одновимірними масивами в мові програмування C++, навчитися будувати блок-схеми алгоритмів та оцінювати їхню складність.

## Хід роботи

1. Ознайомився з умовою лабораторної роботи та поставленим завданням.
2. Створив консольну програму мовою C++ для роботи з одновимірним масивом.
3. Реалізував введення кількості елементів масиву та самих елементів з клавіатури.
4. Знайшов мінімальний елемент масиву, враховуючи можливість наявності декількох однакових мінімальних значень.
5. Обчислив середнє арифметичне всіх елементів масиву та визначив його цілу частину.
6. Заміннив останній мінімальний елемент масиву на цілу частину середнього арифметичного.
7. Вивів змінений масив на екран та перевірив правильність роботи програми.
8. Написав блок-схему по створеному раніше коду.
9. Визначив складність коду.

## Висновок

Під час виконання лабораторної роботи було набуто практичних навичок роботи з одновимірними масивами в мові програмування C++. Закріплено вміння використовувати цикли для обробки масивів, знаходження мінімальних значень та виконання арифметичних обчислень. Отримано досвід роботи в середовищі draw.io та оцінювання складності блок-схем. Отримані результати відповідають умові завдання.

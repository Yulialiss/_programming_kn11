# Звіт
про виконання лабораторної роботи №2 з дисципліни «Алгоритми та структури даних» на тему «Алгоритми обробки масивів»

Виконав: студент групи КН-11 Свиридюк Вадим

Прийняв: ст. викладач Т. Квасниця

## Дубляни 2026

Мета роботи: Сформувати та закріпити практичні навички розробки алгоритмів обробки масивів, оцінювати їх обчислювальну складність та ефективність.

## Хід роботи

1. Ознайомився з умовою лабораторної роботи та вимогами до реалізації програми.
2. Створив консольний застосунок мовою C++ для роботи зі статичним одновимірним масивом розміру N = 100 елементів.
3. Описав структуру програми, яка включає основне меню для вибору операцій та окремі функції для кожного завдання.
4. Реалізував введення кількості елементів масиву n та перевірку коректності введених даних.
5. Реалізував заповнення масиву випадковими цілими числами у заданому діапазоні з використанням генератора випадкових чисел.
6. Розробив алгоритм пошуку простих чисел у масиві та формування нового масиву з цих елементів, а також підрахунок їх кількості.
7. Реалізував алгоритм вставки нового елемента на задану позицію K із попереднім зсувом елементів вправо.
8. Додав перевірку можливих помилкових ситуацій, таких як переповнення масиву або відсутність елементів після обробки.
9. Організував взаємодію з користувачем через текстове меню для поетапного виконання всіх функцій програми.
10. Створив блок-схему до кожного завдання.
11. Визначив для кожного алгоритму часову складність та обсяг пам'яті.

## Висновок

Під час виконання лабораторної роботи було закріплено практичні навички роботи зі статичними масивами в C++. Отримано досвід реалізації алгоритмів обробки масивів, зокрема пошуку простих чисел та вставки елементів зі зсувом. Також закріплено базові навички оцінювання складності алгоритмів.

# Звіт
про виконання лабораторної роботи №3 з дисципліни «Алгоритми та структури даних» на тему «Числові алгоритми: НСД, НСК, алгоритм Евкліда»

Виконав: студент групи КН-11 Свиридюк Вадим

Прийняв: ст. викладач Т. Квасниця

## Дубляни 2026

Мета роботи: Ознайомитися з поняттями найбільшого спільного дільника (НСД) та найменшого спільного кратного (НСК). Вивчити класичний алгоритм Евкліда та його модифікації. Набути практичних навичок реалізації числових алгоритмів мовою C++.

## Хід роботи

1. Ознайомився з теоретичними відомостями про НСД, НСК та алгоритм Евкліда.
2. Створив консольну програму мовою C++ для знаходження НСД чисел.
3. Реалізував алгоритм Евкліда з остачею у вигляді окремої функції.
4. Створив функцію перевірки числа на простоту через НСД.
5. Реалізував перевірку введеного користувачем числа на простоту.
6. Реалізував додаткове завдання — пошук усіх простих чисел від 2 до N.
7. Додав коментарі до коду для пояснення роботи алгоритму.
8. Провів тестування програми та перевірив правильність результатів.
9. Створив блок-схему до коду.

## Висновок

Під час виконання лабораторної роботи було закріплено навички роботи з числовими алгоритмами та алгоритмом Евкліда. Також було вивчено метод перевірки простих чисел через НСД.

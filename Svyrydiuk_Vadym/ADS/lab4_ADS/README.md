# Звіт
про виконання лабораторної роботи №4 з дисципліни «Алгоритми та структури даних» на тему «Розробка алгоритму лінійного пошуку, лінійного пошуку з бар'єром»

Виконав: студент групи КН-11 Свиридюк Вадим

Прийняв: ст. викладач Т. Квасниця

## Дубляни 2026

Мета роботи: Ознайомитися з алгоритмом лінійного пошуку та лінійного пошуку з бар'єром в двовимірних масивах, навчитися знаходити елементи масиву при послідовному обході та визначати їх координати.

## Хід роботи

1. Ознайомився з умовою лабораторної роботи та теоретичними відомостями про лінійний пошук.
2. Розробив алгоритм обходу двовимірного масиву по рядках.
3. Визначив умову пошуку першого від’ємного елемента.
4. Реалізував алгоритм заповнення матриці випадковими числами.
5. Реалізував програму мовою C++ для виконання пошуку.
6. Забезпечив виведення координат знайденого елемента.
7. Провів тестування програми.
8. Перевірив коректність роботи алгоритму.

## Висновок

Під час виконання лабораторної роботи було розглянуто алгоритм лінійного пошуку в двовимірному масиві. Закріплено навички роботи з генерацією випадкових чисел та визначенням координат елементів матриці. Отримано практичний досвід реалізації алгоритмів пошуку мовою C++.

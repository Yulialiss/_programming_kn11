# Звіт
про виконання лабораторної роботи №5 з дисципліни «Алгоритми та структури даних» на тему «Аналіз методів сортування»

Виконав: студент групи КН-11 Свиридюк Вадим

Прийняв: ст. викладач Т. Квасниця

## Дубляни 2026

Мета роботи: Ознайомитися з методами сортування масивів, реалізувати алгоритм швидкого сортування методом Ломуто у порядку спадання та дослідити його складність.

## Хід роботи

1. Ознайомився з теоретичними відомостями про алгоритми сортування та принцип роботи швидкого сортування.
2. Розглянув метод розподілу Ломуто та принцип вибору опорного елемента (pivot).
3. Створив алгоритм швидкого сортування масиву у текстовому вигляді.
4. Реалізував програму мовою C++ для сортування масиву методом Quick Sort у порядку спадання.
5. Реалізував функцію розподілу Ломуто для перестановки елементів відносно опорного елемента.
6. Реалізував рекурсивну функцію швидкого сортування масиву.
7. Реалізував виведення відсортованого масиву на екран.
8. Визначив часову та просторову складність алгоритму швидкого сортування.
9. Розробив блок-схему алгоритму швидкого сортування.
10. Провів тестування програми на різних наборах даних.

## Висновок

Під час виконання лабораторної роботи було вивчено принцип роботи алгоритму швидкого сортування та методу розподілу Ломуто. Закріплено навички реалізації рекурсивних алгоритмів мовою C++. Також було досліджено часову та просторову складність алгоритму Quick Sort і проведено тестування його роботи на різних наборах даних.

# Звіт
про виконання лабораторної роботи №6 з дисципліни «Алгоритми та структури даних» на тему «Розробка рекурсивних алгоритмів»

Виконав: студент групи КН-11 Свиридюк Вадим

Прийняв: ст. викладач Т. Квасниця

## Дубляни 2026

Мета роботи: Ознайомитися з принципом роботи рекурсивних алгоритмів та закріпити навички роботи з рекурсією у мові програмування C++.

## Хід роботи

1. Ознайомився з теоретичними відомостями про рекурсивні алгоритми.
2. Розглянув принцип роботи рекурсивних викликів функцій.
3. Ознайомився з формулою обчислення кількості комбінацій.
4. Створив алгоритм обчислення комбінацій у текстовому вигляді.
5. Реалізував рекурсивну функцію для обчислення значення C(n, m).
6. Реалізував базові випадки рекурсії: якщо m = 0 або m = n, результат дорівнює 1; якщо m > n, результат дорівнює 0.
7. Реалізував рекурсивне обчислення через формулу: C(n-1, m-1) + C(n-1, m).
8. Реалізував введення значень n та m користувачем.
9. Реалізував виведення результату роботи програми.
10. Розробив блок-схему алгоритму.

## Висновок

Під час виконання лабораторної роботи було реалізовано рекурсивний алгоритм обчислення кількості комбінацій. Закріплено навички роботи з рекурсивними функціями та базовими випадками рекурсії.

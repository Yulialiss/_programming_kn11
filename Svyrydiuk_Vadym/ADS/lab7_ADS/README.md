# Звіт
про виконання лабораторної роботи №7 з дисципліни «Алгоритми та структури даних» на тему «Моделювання роботи стеку та черги»

Виконав: студент групи КН-11 Свиридюк Вадим

Прийняв: ст. викладач Т. Квасниця

## Дубляни 2026

Мета роботи: Ознайомитися з принципами роботи лінійних структур даних «стек» та «черга», а також закріпити навички їх програмної реалізації мовою C++.

## Хід роботи

1. Ознайомився з теоретичними відомостями про структури даних, такі як стек та черга.
2. Розглянув принцип роботи стеку за правилом LIFO (останнім прийшов — першим вийшов).
3. Розглянув принцип роботи черги за правилом FIFO (першим прийшов — першим вийшов).
4. Створив програмну реалізацію стеку на базі статичного масиву.
5. Реалізував основні операції інтерфейсу стеку у вигляді методів структури.
6. Реалізував перевірку помилкових ситуацій (переповнення та спустошення стеку).
7. Розробив меню для взаємодії користувача з програмою.
8. Реалізував індивідуальне завдання, яке передбачає використання стеку для обробки символьного рядка та знаходження пар квадратних дужок.
9. Розробив блок-схему алгоритму індивідуального завдання.

## Висновок

Під час виконання лабораторної роботи було реалізовано структуру даних стек та закріплено практичні навички роботи з лінійними структурами даних. Також було реалізовано індивідуальне завдання з використанням стеку для аналізу символьного рядка та роботи з дужками.

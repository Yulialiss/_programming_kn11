## Дубляни 2026

Мета: Ознайомитися з базовою структурою програми на C++ (ввід/вивід, змінні, рядки, форматування), навчитися ініціалізувати Git-репозиторій, робити коміти та публікувати код у віддалений репозиторій (GitHub).

## Хід роботи

1. Відкрити проект у Visual Studio.
2. Переконатися, що встановлено C++17 або новішу версію.
3. Зібрати проект.
4. Запустити програму.
5. Ввести потрібні дані згідно запитів програми.
6. Переконатися, що програма виведе правильний результат.

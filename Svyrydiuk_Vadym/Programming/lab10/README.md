# Звіт
про виконання лабораторної роботи №10 з дисципліни "Програмування" на тему "Вказівники в мові програмування C++".

Виконав: студент групи КН-11 Свиридюк Вадим

Прийняв: ст. викладач Т. Квасниця

## Дубляни 2026

Мета: Ознайомитися та навчитися використовувати використовувати вказівники при написанні програм на мові C++.

## Хід роботи

1. Ознайомився з теоретичними відомостями про вказівники та роботу з рядками у C++.
2. Створив програму для перевірки сьомої з кінця літери рядка за допомогою вказівника.
3. Реалізував перевірку символу на відповідність літерам "s" або "w".
4. Створив масив вказівників на окремі літери слова.
5. Реалізував сортування кожної другої літери за кодами символів.
6. Побудував блок-схеми алгоритмів відповідно до індивідуальних завдань.
7. Перевірив правильність роботи програм та проаналізував отримані результати.

## Висновок

У результаті виконання лабораторної роботи було закріплено навички роботи з вказівниками та рядками у мові C++. Було реалізовано доступ до елементів рядка через адреси пам’яті, створення масиву вказівників та сортування символів.

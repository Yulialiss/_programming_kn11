# Звіт
про виконання лабораторної роботи №5 на тему «Двовимірні масиви»

Виконав: студент групи КН-11 Свиридюк Вадим

Прийняв: Т. Квасниця

## Дубляни 2026

Мета роботи: Ознайомитися з двовимірними масивами (матрицями) в мові програмування C++, навчитися виконувати введення та обробку елементів матриці, а також використовувати вкладені цикли для аналізу її рядків і стовпців.

## Хід роботи

1. Ознайомився з умовою лабораторної роботи та поставленим завданням.
2. Створив консольну програму мовою C++ для роботи з двовимірним масивом (матрицею).
3. Реалізував введення кількості рядків n та стовпців m матриці.
4. Реалізував введення елементів матриці з клавіатури за допомогою вкладених циклів.
5. Перевірив кожен стовпець матриці на впорядкованість елементів за зростанням.
6. Визначив стовпці, у яких кожний наступний елемент більший за попередній.
7. Вивів номери таких стовпців на екран.

## Висновок

Під час виконання лабораторної роботи було отримано практичні навички роботи з двовимірними масивами (матрицями) в мові програмування C++. Закріплено вміння використовувати вкладені цикли для введення та обробки елементів матриці. Також було реалізовано алгоритм перевірки впорядкованості елементів стовпців за зростанням. Отримані результати відповідають поставленій умові завдання.

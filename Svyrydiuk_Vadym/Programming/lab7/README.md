# Звіт
про виконання лабораторної роботи №7 на тему «Робота зі стрічками»

Виконав: студент групи КН-11 Свиридюк Вадим

Прийняв: Т. Квасниця

## Дубляни 2026

Мета роботи: Ознайомитися з обробкою рядків у мові програмування C++, навчитися розбивати текст на слова.

## Хід роботи

1. Ознайомився з умовою лабораторної роботи та поставленим завданням.
2. Розробив консольну програму мовою C++ для обробки рядка, що містить слова, розділені комами та завершені крапкою.
3. Реалізував введення рядка за допомогою функції getline.
4. Виконав розбиття рядка на окремі слова.
5. Зберіг отримані слова у масиві.
6. Реалізував сортування слів у алфавітному порядку.
7. Вивів відсортовані слова у заданому форматі.

## Висновок

У ході виконання лабораторної роботи було отримано практичні навички роботи зі стрічками у мові програмування C++. Закріплено знання обробки символів, формування слів із рядка та роботи з масивами рядків. Було реалізовано алгоритм сортування слів у алфавітному порядку за допомогою бульбашкового методу. Отримані результати відповідають поставленій задачі.

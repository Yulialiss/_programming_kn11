# Звіт
про виконання лабораторної роботи №9 з дисципліни "Програмування" на тему "Робота з текстовими файлами".

Виконав: студент групи КН-11 Свиридюк Вадим

Прийняв: ст. викладач Т. Квасниця

## Дубляни 2026

Мета: Ознайомитися із роботою з текстовими файлами в C++, навчитися створювати файли, записувати та зчитувати інформацію, а також виконувати обробку даних із файлів.

## Хід роботи

1. Ознайомився з теоретичними відомостями про роботу з текстовими файлами у C++.
2. Створив програму для запису та зчитування текстових даних із файлів.
3. Реалізував пошук послідовностей цифр у файлі та запис результатів у інший файл.
4. Створив структуру "Car" для збереження інформації про автомобілі та їх власників.
5. Реалізував додавання та перегляд записів у файлі "cars.txt".
6. Реалізував пошук і сортування власників автомобілів за заданими параметрами.
7. Перевірив коректність роботи програм та отриманих результатів.

## Висновок

У результаті виконання лабораторної роботи було закріплено навички роботи з текстовими файлами в мові C++. Було реалізовано запис, зчитування та обробку інформації у файлах, а також використано структури, масиви та сортування даних.

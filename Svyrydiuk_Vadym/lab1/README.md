# Lab 1: First C++ program + Git (I/O only)

## Варіант 12

## Короткий опис задачі
Мета лабораторної роботи:
1. Ознайомитися з базовою структурою програми на C++ (ввід/вивід, змінні, рядки, форматування).
2. Навчитися ініціалізувати Git-репозиторій, робити коміти та публікувати код у віддалений репозиторій (GitHub).

Програма зчитує введені користувачем дані та виводить їх разом з інформацією про лабораторну, варіант і ПІБ студента.

## Інструкція запуску
1. Відкрити проект у Visual Studio.
2. Переконатися, що встановлено C++17 або новішу версію.
3. Зібрати проект.
4. Запустити програму.
5. Ввести потрібні дані згідно запитів програми.
6. Програма виведе:
   - назву лабораторної
   - номер варіанту
   - ПІБ студента
   - інші введені дані

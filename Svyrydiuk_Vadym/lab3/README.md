## Львів 2026

Мета: Ознайомитися з циклами в C++ та їхніми видами - for, while, do while.

## Хід роботи

1. Ознайомився з умовою лабораторної роботи та завданнями, які необхідно реалізувати мовою C++.
2. Створив консольну програму для реалізації лабораторної роботи.
3. Для першого завдання реалізував табуляцію заданої функції на відрізку з використанням циклу for.
4. У процесі виконання циклу здійснив перевірку значень функції та обчислив суму та добуток від'ємних значень.
5. Для другого завдання реалізував обчислення добутку за заданою формулою з використанням циклу.
6. Після виконання обчислень отримані результати перевірив на коректність.

## Висновок

У результаті роботи було отримано коректні результати, а також закріплено навички роботи з циклами, умовними операторами та арифметичними обчисленнями в мові програмування C++.

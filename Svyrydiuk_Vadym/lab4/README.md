# Звіт
про виконання лабораторної роботи №4 з дисципліни «Програмування» на тему «Одновимірні масиви»

Виконав: студент групи КН-11 Свиридюк Вадим

Прийняв: Н. Заплатинський

## Львів 2026

Мета роботи: Ознайомитися з одновимірними масивами в мові програмування C++, навчитися виконувати введення та обробку елементів масиву, а також застосовувати цикли для аналізу та зміни його значень.

## Хід роботи

1. Ознайомився з умовою лабораторної роботи та поставленим завданням.
2. Створив консольну програму мовою C++ для роботи з одновимірним масивом.
3. Реалізував введення кількості елементів масиву та самих елементів з клавіатури.
4. Знайшов мінімальний елемент масиву, враховуючи можливість наявності декількох однакових мінімальних значень.
5. Обчислив середнє арифметичне всіх елементів масиву та визначив його цілу частину.
6. Заміннив останній мінімальний елемент масиву на цілу частину середнього арифметичного.
7. Вивів змінений масив на екран та перевірив правильність роботи програми.

## Висновок

Під час виконання лабораторної роботи було набуто практичних навичок роботи з одновимірними масивами в мові програмування C++. Закріплено вміння використовувати цикли для обробки масивів, знаходження мінімальних значень та виконання арифметичних обчислень. Отримані результати відповідають умові завдання.

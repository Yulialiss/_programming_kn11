## Дубляни 2026

Мета роботи: Ознайомитися з використанням функцій у мові програмування C++ для обробки двовимірних масивів (матриць).

## Хід роботи

1. Ознайомився з умовою лабораторної роботи та поставленим завданням.
2. Розробив консольну програму мовою C++ для роботи з квадратною матрицею розміру n*n.
3. Реалізував введення розміру матриці та її елементів за допомогою вкладених циклів.
4. Створив функцію maxRow, яка визначає максимальний елемент кожного рядка матриці.
5. Створив функцію minCol, яка знаходить мінімальний елемент кожного стовпця матриці.
6. Реалізував функцію calculate, яка обчислює суму добутків максимальних елементів рядків і мінімальних елементів відповідних стовпців: 𝑥0*𝑦0 + 𝑥1*𝑦1 + ⋯ + 𝑥𝑛−1*𝑦𝑛−1​
7. Вивів отриманий результат на екран.

## Висновок

У ході виконання лабораторної роботи було отримано практичні навички використання функцій у мові програмування C++ для обробки двовимірних масивів. Закріплено знання роботи з вкладеними циклами та передачею масивів у функції. Було реалізовано алгоритм знаходження максимальних елементів рядків і мінімальних елементів стовпців, а також обчислення суми їх попарних добутків. Отримані результати відповідають поставленій задачі.

# Звіт
про виконання лабораторної роботи №8 на тему «Структури»

Виконав: студент групи КН-11 Свиридюк Вадим

Прийняв: Т. Квасниця

## Дубляни 2026

Мета роботи: Ознайомитися з використанням структур у мові програмування C++, навчитися працювати з масивами структур.

## Хід роботи

1. Ознайомився з умовою лабораторної роботи та поставленим завданням.
2. Описав структуру Animal, яка містить такі поля: назва, середня тривалість життя, швидкість пересування та чисельність популяції.
3. Реалізував введення даних для довільної кількості тварин із клавіатури.
4. Зберіг введені дані у масив структур.
5. Реалізував пошук найшвидшої тварини шляхом порівняння значень швидкості.
6. Визначив тварину з найменшою чисельністю популяції.
7. Виконав сортування масиву структур за чисельністю популяції у порядку спадання за допомогою бульбашкового методу.
8. Вивів результати роботи програми: найшвидшу тварину, тварину з найменшою популяцією та відсортований список.

## Висновок

У ході виконання лабораторної роботи було отримано практичні навички використання структур у мові програмування C++. Закріплено знання роботи з масивами структур, реалізації алгоритмів пошуку мінімальних та максимальних значень, а також сортування даних за заданим критерієм. Отримані результати відповідають поставленій задачі.
